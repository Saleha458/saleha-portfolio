A modern, responsive, and dynamic professional portfolio built to showcase my development skills, projects, professional experience, education, certifications, and technical background.

## Local Development

Clone the repository:

```bash
git clone https://github.com/Saleha458/saleha-portfolio.git
```

Navigate to the project:

```bash
cd saleha-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

## Environment Variables

Create a `.env` file in the project root and configure the environment variables required by the application.

Environment files are excluded from Git through `.gitignore`.

Do not commit private credentials or secret keys to the repository.

## Deployment

The portfolio is configured for deployment on Vercel.

Production deployment uses:

```bash
npm run build
```

with:

```text
dist
```

as the Vite output directory.

## Content Management

Most portfolio content is stored dynamically in Firebase.

This means projects, skills, experience, education, certificates, resume information, personal information, and AI settings can be updated through the admin dashboard without changing the React source code.

# Saleha Imtiaz — Developer Portfolio

A modern, responsive, and dynamic professional portfolio showcasing my projects, skills, experience, education, certifications, and development work.

The portfolio includes a **private admin dashboard** for dynamic content management and an **AI-powered Digital Twin** that answers questions about my professional profile.

🌐 **Live Portfolio:** https://saleha-portfolio.vercel.app

## ✨ Features

Fully responsive modern UI
Light & dark theme
Dynamic portfolio content
Private admin dashboard
Projects, skills, experience & education management
Certificate and resume management
Contact form with email notifications
AI-powered Digital Twin
Firebase Authentication & Firestore
Firebase App Check protection
Cloudinary media management
SEO & SPA routing
Production deployment on Vercel

## 🛠 Tech Stack

**Frontend:** React.js, Vite, JavaScript, Tailwind CSS, Framer Motion  
**Database & Auth:** Firebase, Cloud Firestore, Firebase Authentication  
**AI:** Firebase AI Logic, Gemini, Firebase App Check, reCAPTCHA Enterprise  
**Services:** Cloudinary, EmailJS  
**Deployment:** Vercel  
**Tools:** Git, GitHub, npm, VS Code

## 🤖 AI Digital Twin

The portfolio features **Saleha's AI Twin**, an interactive AI assistant that answers questions about my skills, projects, experience, education, certifications, and professional background using dynamic portfolio data.

## ⚙️ Admin Dashboard

A private Firebase-authenticated dashboard allows portfolio content to be managed without editing the source code, including projects, skills, experience, education, certificates, resume, personal information, contact messages, and AI settings.

## 🚀 Run Locally

```bash
git clone https://github.com/Saleha458/saleha-portfolio.git
cd saleha-portfolio
npm install
npm run dev
```

Create a `.env` file and configure the required Firebase App Check, Cloudinary, and EmailJS environment variables.
